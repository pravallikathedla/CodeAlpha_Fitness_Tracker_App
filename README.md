# Fitness Tracker App

## Project Overview

The Fitness Tracker App is a web-based application that helps users monitor and manage their daily fitness activities. Users can record workout details such as steps taken, workout type, workout duration, and calories burned. The application provides a dashboard that displays fitness progress and helps users stay motivated toward their health goals.

The application uses Local Storage to save user data, ensuring that fitness records remain available even after refreshing the browser.

## Features

* Track daily steps.
* Log workout type and duration.
* Record calories burned.
* Dashboard displaying fitness information.
* Progress bar for visual tracking.
* Data persistence using Local Storage.
* Simple and responsive user interface.
